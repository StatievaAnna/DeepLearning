# Постановка задачи

Внедрить правильные тесты для обучающего конвейера.

Реализовать функцию test_training в test_pipeline.py , которая запускает интеграционный тест для всей процедуры обучения с разными гиперпараметрами и ожидает разные результаты. Этот тест должен увеличить охват кода (измеренный с помощью pytest-cov) до >80%. 

Тестовый код, запускающий реальную модель, должен выполняться как на CPU, так и на GPU.
