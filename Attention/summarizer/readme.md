## 1. Постановка задачи 

### Описание задачи

## Применение модели

**Задача № 1** Добавить генератор суммаризации для модели, привести демонстрацию результата для 5 примеров из теста и 5 собственных примеров. 

**Задача № 2** Добавить оценку для модели с помощью ROUGE metric.

**Задача № 3** Добавить визуализацию механизма attention после обучения модели на конкретном примере (не менее 3 примеров). 

**Задача № 4** Сделать общими матрицы эмбеддингов - их тут три (входные в энкодер и декодер + выход декодера).

**Задача № 5** Заменить функцию ошибки на LabelSmoothing.

**Задача № 6** Добавить предодученные эмбединги при обучении модели, проанализировать разницу в метрике до и после.
